# SIRIUS 경과관찰 구현과 검증

2026-11-10 기준 로컬 구현. 공개 배포·임상 검증 보고서가 아니다.

## 바뀐 동작

로그인 뒤 첫 화면을 위치 맞춤 경과관찰로 구성했다. 위치 6개와 모름, MRI 크기와 촬영일·예정일, 양손 10초 탭과 한눈씩 4방향 자극, 개인 기준점 비교, 날짜·단위별 그래프, 진료 요약을 제공한다. 후각·청력·보호자·약물 기록도 추가했다. 기존 영상 보기와 고급 격자 시야·암호화 파일 기능은 유지한다.

기본 로그인은 이메일을 수집하지 않는 이 기기 전용 방식이다. 기존 PBKDF2와 AES-GCM 보관함에 followup을 포함해 저장·복원한다. 새 계정은 이전 평문 기록을 자동으로 이어받지 않는다. 로그아웃이나 화면 이탈은 측정 타이머와 임시 상태를 정리한다. 저장 실패를 알리고 재시도할 수 있으며, 다른 계정에 늦은 저장 결과를 반영하지 않는다. 인쇄/복사 전에 민감한 자료의 외부 출력임을 안내한다.

## 실제 검증

- JavaScript 문법 및 참조 검사 40개 파일 통과.
- 최종 JavaScript 회귀 검사 132개 통과. 기존 고급 시야와 암호화 파일 시험 포함.
- 격리된 실제 Edge 브라우저에서 합성 계정으로 가입, 위치/MRI 입력, 양손 탭 타이머, 4방향 시야 순서, 저장·로그아웃·재로그인 복원, 계정 분리, 저장 실패 안내를 검증했다.
- 같은 흐름에서 외부 POST 요청과 브라우저 실행 오류가 없었다. 이 확인은 모든 가능한 경로에 대한 외부 침투 테스트를 뜻하지 않는다.
- 데스크톱 및 390px 모바일 화면을 확인했고, 페이지 전체 가로 넘침이 없었다. 탭/시야 측정 중 배경 접근 차단과 Tab 포커스 순환도 적용했다.
- 실제 PDF 출력에서 진료 요약은 A4 1페이지였다. 모든 종류의 체크와 긴 비교 문구를 넣은 합성 사례도 1페이지였다.
- 기존 영상 보기에서도 앱의 합성 예시로 Node 서버와 로컬 EfficientNet 추론 서버 간 결과 왕복을 검증했다. 이 검사는 정확도 평가가 아니다.
- 비밀 설정·실제 환자 기록·원본 영상은 테스트에 사용하지 않았다. 새 의존성 설치나 모델 재학습은 수행하지 않았다.

## 해석과 한계

탭과 간단 시야의 비교 기준은 앱의 표시 규칙이며 의학적 정상 범위나 임상 임계치가 아니다. 날짜가 다른 MRI와 체크로 엇갈림을 판단하지 않는다. 위치·크기는 판독지를 보고 사용자가 입력하며 AI가 자동 추정하지 않는다. 브라우저/기기 간 동기화는 없고, 브라우저 데이터를 지우면 복구 키만으로 기록을 재생성할 수 없다. 카메라 자동 진단이나 음성 외부 전송은 추가하지 않았다. 기존 모델의 정확도나 임상 성능이 향상됐다는 의미가 아니다.

## 의학 설명 확인에 사용한 일차 출처

수막종 증상은 위치에 따라 다를 수 있다. [NCI 수막종 설명](https://www.cancer.gov/rare-brain-spine-tumor/tumors/meningioma), [MSD 위치별 증상](https://www.msdmanuals.com/professional/oncology/central-nervous-system-tumors/meningiomas)을 참고했다. 이 정보가 새 자가 체크의 진단 정확도를 입증하지는 않는다.

메드록시프로게스테론 관련 위험 정보는 [EMA 의료인 안내](https://www.ema.europa.eu/en/medicines/dhpc/medroxyprogesterone-acetate) 및 [FDA Depo-Provera 라벨](https://www.accessdata.fda.gov/drugsatfda_docs/label/2025/020246s074lbl021583s045lbl.pdf)에 근거한다. 앱은 사용 이력을 진료에 알리도록 기록하며 약 중단을 직접 지시하지 않는다.

긴급 증상 안내는 [NHS 뇌종양 증상 안내](https://www.nhs.uk/conditions/malignant-brain-tumour/symptoms/) 등 공신력 자료를 검토했다. 한국 응급 연락은 119로 표시한다. 개별 환자의 진료·검사 일정은 담당 의료진과 정한다.
