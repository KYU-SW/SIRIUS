# 위치 맞춤 경과관찰 보완 기록 — 2026-11-11

## 반영한 변경

- 실명 대신 선택 별명을 안내하고 로컬 계정의 이메일 표시를 제거했다.
- 계정 쓰기에 Web Locks와 변경 전 스냅샷 비교를 적용했다. 다른 탭의 동일 계정 변경은 이전 세션을 잠근다.
- 신규 키 도출은 PBKDF2-SHA256 600,000회를 사용한다. 기존 비밀번호와 복구 키 포장의 반복 횟수는 각각 보존한다.
- 경과관찰 전용 암호화 파일의 내보내기·미리보기·명시적 교체·실패 시 복원·세션 취소 처리를 추가했다.
- 고급 시야 파일 작업에도 세션 확인을 적용해 로그아웃·화면 이동 뒤 다운로드나 옛 기록 복원이 일어나지 않게 했다.
- 간단 시야 도중 화면 폭·배율이 바뀌면 측정을 기록하지 않고 중단한다.
- 보호자가 관찰한 얼굴 움직임 변화의 고정 항목을 추가했다. 카메라 처리나 자동 판정은 없다.
- 가입·비밀번호 변경을 저장 직전 취소하면 늦은 쓰기와 복구 키 표시를 막는다. 화면 이동·로그아웃 때 숨은 인증 입력란도 비운다.
- 로그인 후 인증 화면에서도 유휴 잠금을 유지하고, 홈으로 나갈 때 보관함을 잠근다.
- 일반 경과관찰 저장에도 세션·요청 세대를 확인해 이전 저장의 늦은 결과가 최신 표시를 바꾸지 못하게 했다.

## 검증한 범위

JavaScript 43개 문법과 HTML 스크립트 경로 검사를 통과했다. 전체 Node 회귀 테스트는 170개 통과, 실패 0개였다. 합성 자료만 사용했다. 실제 격리 Edge 브라우저에서도 가입·로그인·탭/시야 검사·암호화 저장/재로그인·계정 분리·저장 실패·모바일·인쇄를 확인했다. 별도 검사에서는 두 탭 잠금과 경과관찰 및 고급 시야 암호화 파일 왕복, 화면 이동 후 늦은 내보내기 취소를 확인했다.

이 수치는 해당 시점의 검증 기록이다. 이전 2026-11-10 구현 보고서의 테스트 수는 당시 점검 결과다. 이후 변경에는 다시 필요한 검증을 수행한다.

후속 점검: 전체 Node 검사는 176개 통과했다. 이후 인증 화면의 유휴 잠금·홈 이동 보완에 대한 관련 검사 41개도 통과했다. Python 합성 자료 기반 회귀 검사 26개가 통과했다. 실제 Edge에서는 시야 자극 영역 폭 변경 시 기록 없이 중단·타이머 정리·앱 조작 복구를 확인했고, 가입 저장 직전 홈으로 이동하면 계정 생성과 복구 키 화면 표시가 취소되는 것도 확인했다.

## 남아 있는 한계

임상 유효성·외부 침투 테스트를 검증한 것은 아니다. 시야·탭 결과는 같은 조건에서 자기 기록을 비교하는 보조 수치다. 새로운 모델 학습이나 독립 데이터 정확도 개선은 이번 웹 보완에서 수행하지 않았다. 브라우저 데이터가 삭제되면 복구 키만으로 기록을 재생성할 수 없으므로 사용자가 별도 백업을 보관해야 한다. 현재 변경은 로컬 작업 상태이며 이 보고서는 GitHub 게시 완료를 의미하지 않는다.
